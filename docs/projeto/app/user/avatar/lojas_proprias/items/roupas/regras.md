> **Caminho:** `app/user/avatar/lojas_proprias/items/roupas` · **Pai:** [items](../regras.md) · **Status:** ✅ Implementado

## Regras
1. Roupas 3D criadas pelo usuário via formulário UGC.
2. Cada peça define gênero (`Universal`, `Male`, `Female`), slot anatômico oficial, mesh base `prefabs` e parâmetros de shader.
3. Rende 70% de royalties ao avatar criador a cada compra realizada no marketplace.
