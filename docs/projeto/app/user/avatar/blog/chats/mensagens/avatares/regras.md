# Avatares no Chat

> **Caminho:** `app/user/avatar/blog/chats/mensagens/avatares` · **Pai:** [mensagens](../regras.md) · **Status:** ✅ Implementado

## Regras
1. Cada mensagem exibe o avatar do remetente (foto miniatura `thumbnail`, nome e gênero).
2. Se o avatar for assinante ativo, exibe o selo distintivo **`👑 VIP`** ao lado do nome.
3. Se o avatar tiver um selo de carreira equipado, renderiza o ícone de conquista (ex: 🧭, ✒️, 💎, 💖, 🏠).
4. Avatares que bloquearam ou foram bloqueados pelo usuário não têm mensagens entregues em DMs.
